# AI-Assisted Development

## Specification-First
The requirements were defined before implementing the program.

## Type-Driven Development
Python type hints were used to specify input and output types.

## Test-First Development
Test cases were created to verify the expected behavior.

## AI Assistance
AI was used to generate and review the initial implementation
based on the specification.

## Manual Verification
The generated code was manually reviewed and executed.

## Result
All tests passed successfully.
